Retail Customer Retention Analysis Power BI Data Analytics Project Customer Retention • Churn • Loyalty • Store Performance About the Project This project analyzes customer retention and churn for a retail business using Target as the case study. The project uses customer demographics, transactions, store locations, loyalty program information and churn-labelled customer data. Tools Used Power BI • Power Query • DAX • Data Analysis Project Statistics 200 Total Customers 191 Repeat Customers 49 Churned Customers 24.50% Churn Rate Dashboard Analysis 01 — Customer Retention Overview Overview of customer retention, repeat customers and churn. 02 — Loyalty & Promotion Analysis Analysis of loyalty tiers, promotions and loyalty points. 03 — Store & Channel Performance Analysis of store types and purchasing channels. 04 — Customer Segmentation Analysis of customer segments, purchase behavior and customer value. Key Findings • Overall churn rate was 24.50%. • 191 customers were repeat customers. • 49 customers were churned. • Medium income customers had a 26.92% churn rate. • Low income customers had a 19.64% churn rate.
